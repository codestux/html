# HTML

# O que é HTML

HTML - Hypertext Markup Language(Linguagem de Marcação de Hipertexto).

Ela é responsável pela construção da estrutura de uma página HTML(Web) e seu conteúdo e indica ao navegador o tipo de informação que precisa ser exibida.

É muito importante escrever HTML semântico.

A parte visual deve ser tratada pela CSS.

O HTML e o CSS são as bases para a construção de sites.

# Tipos de Desenvolvimento

O desenvolvimento Web pode ser dividido em duas partes. O **Back-end** é a parte que fica por trás das coisas visuais de uma aplicação e o **Front-end** é a parte visual(não somente isso) e onde ocorrem as interações com o usuário durante o uso do aplicativo.

As habilidades atuais básicas para construir aplicações Web são: Lógica, HTML, CSS e JavaScript/TypeScript
